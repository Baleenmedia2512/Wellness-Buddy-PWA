# Events

The Events page currently presents three clearly marked sample wellness events
in colorful cards. Sample dates, times, and venues are for preview only and are
not confirmed. Each Register action opens a dedicated form containing only a
name field. Registration confirmation is held only in component state; it is
not saved or sent to a server. Replace sample details when actual event data or
an events API is available.

The page is gated by the frontend-only `ff.events` flag.
